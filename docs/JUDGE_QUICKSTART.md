# 裁判运行指南

## 1. 原型机与网络

使用作品随附的已配置原型机时，给原型机供电，确认其能连到有互联网的 Wi-Fi。更换现场网络时，通过灵机平台原有 BLE 配网流程填写自己的 Wi-Fi；不要清空配网或重新烧录空凭据发布镜像。自行部署另一台设备时，先按 [配置与烧录](CONFIGURE_BUILD_FLASH.md) 完成产品密钥、网络和云端配置。

电脑与原型机必须能通过局域网互相访问。记录原型机的实际 IP（通过网络设备列表或设备启动信息查看），不要假设一直是 `172.20.10.2`。可先在浏览器访问 `http://设备IP/`，再检查 `http://设备IP:81/api/control`。

只连接相机 AP 不会自动获得云端互联网。若使用 AP，AP 名称及密码需按公开源码中的留空配置自行设置；已交付原型机已有配置时，以该原型机的实际网络设置为准。

## 2. 在同一目录安装、启动

Windows 10/11 x64，推荐 **Python 3.12 x64**。从 [Python 官方页面](https://www.python.org/downloads/windows/) 选择 3.12 系列的 Windows 64 位安装程序，勾选 **Add python.exe to PATH**，安装后重新打开终端。不要用最新 3.13+ 代替本项目要求的版本。

完整解压本项目后，打开：

```text
runtime\Xiaoling_Tracker_LJYD\
```

双击此文件夹里的 `setup_pc.cmd`，等依赖安装完成。首次安装需联网；模型文件已随包提供。不要在 `source/` 里安装完后到另一目录启动。

在**这个文件夹**打开 PowerShell，启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_pc.ps1 -DeviceHost "设备的实际IP" -Rotate 90
```

例如设备当前 IP 是 `192.168.1.50`：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_pc.ps1 -DeviceHost "192.168.1.50" -Rotate 90
```

只有设备实际地址为默认值 `172.20.10.2` 时，才直接双击 `run_pc.cmd`。移动整个目录后，其自身 `.venv` 可能失效，应在新位置重跑同目录的 `setup_pc.cmd`；不要只拖动一个脚本。

## 3. 建议演示顺序

1. 图像出现后，说“你好小灵”，问一个普通问题。
2. 说“开始追踪脸”，观察双轴追踪；说“停止追踪”停止。
3. 说“开始坐姿检测”，等摄像头停稳，坐直并让鼻子、双眼、双肩进入画面，再说“校准坐姿”。
4. 观察坐姿提示；必要时说“暂停坐姿追脸”固定镜头。
5. 说“停止聊天”，随后说“校准坐姿”或“开灯”，确认指令执行且没有确认语；再说“你好小灵”恢复语音。
6. `Q` 退出窗口。“退出电脑程序”也会关闭程序，下次使用需要重新启动。

## 4. 常见问题

| 现象 | 检查 |
| --- | --- |
| 提示先运行 setup | 确认当前目录是 `runtime/Xiaoling_Tracker_LJYD`；在此目录运行 `setup_pc.cmd`，不要复用另一目录的环境 |
| 找不到 python | 安装 Python 3.12 x64 并加入 PATH，重开终端；或运行 `powershell -ExecutionPolicy Bypass -File .\setup_pc.ps1 -Python "你自己的python.exe完整路径"` |
| 依赖／模型导入失败 | 保留整个目录，检查安装是否成功；不要混用多个 OpenCV 发行包或替换固定依赖版本 |
| 窗口有界面但无图像 | 核对 `-DeviceHost`、局域网可达性、原型机供电及相机连接；浏览器检查设备图像服务 |
| 语音完全不可用 | 检查产品密钥、平台发布／绑定、Wi-Fi 互联网连接；公开留空凭据镜像需要先配置后重编译 |
| 指令执行却不说话 | 可能处于“停止聊天”后的静音模式，说“你好小灵”恢复 |
| 坐姿校准未完成 | 摄像头停稳后重新坐直，确保关键点可见；电脑程序必须保持运行 |

程序会自动创建自己的运行日志目录。完整解压并按同目录步骤操作，可避免之前“安装目录与启动目录不一致”的问题；本项目仍需要满足 Python、网络和设备配置条件。
