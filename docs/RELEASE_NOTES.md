# 小灵比赛提交版 v3.1.2

- ESP32-S3 双轴手／脸追踪、坐姿识别与校准、灯光和灵机语音联动。
- 修复普通聊天在一次播放错误后持续无声的问题。
- “停止聊天”只关闭语音，静音时仍执行控制指令；再次唤醒恢复说话。
- 电脑端保留已修复的目录与环境查找脚本；裁判在 runtime/Xiaoling_Tracker_LJYD 同目录安装并启动。
- 产品密钥、Wi-Fi 和 API 由使用者自行配置，发布固件从空配置源码重新编译。
- 包含完整源码、厂商依赖快照、模型、空配置固件、原版电脑程序、裁判指南、上传指南与文件校验清单。
