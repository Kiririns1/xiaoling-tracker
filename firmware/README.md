# ESP32-S3 空配置发布镜像

本目录镜像从 source/ 的留空配置源码重新编译，功能版本为 3.1.2-silent-controls，产品密钥与 Wi-Fi 配置为空。它不包含开发者的可用平台密钥，也不包含 NVS／Wi-Fi／设备证书备份。

请先阅读 ../docs/CONFIGURE_BUILD_FLASH.md，在自己的私有副本填写产品及网络配置，再编译烧录。不要期望本目录镜像在未配置时直接连云。现有已配置原型机无需为运行电脑端而重新刷机。

flash_args 与 app-flash_args 中的路径均相对于本目录。跨分区布局需使用配套启动镜像和分区表；同布局只更新应用前要核对活动 OTA 槽。本提交未向原型机写入空配置镜像。
