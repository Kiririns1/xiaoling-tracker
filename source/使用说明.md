## 说话方式

联网并连云后进入**在线待唤醒**。说“你好小灵”或“你好小林”唤醒，也兼容单独叫“小灵/小林”。固件不更改设备名字，回复自称小灵。

唤醒后直接继续说话，无须每轮叫名字。“停止聊天”只关闭语音输出，直到再次被唤醒。期间继续接收并执行追踪、坐姿、校准、灯光及平台控制指令，指令确认语、坐姿提醒和番茄时钟通知都保持静音。它不关闭已有追踪、检测或计时任务；“停止追踪”“关闭坐姿检测”和“停止番茄时钟”分别关闭对应任务。

**唤醒是联网语音识别方案**：SDK 没有修改 VB701N 离线关键词模型的接口，因此待唤醒时仍向灵机上传麦克风音频并接收 ASR；控制指令不依赖唤醒，只有语音回复需要唤醒后才播放。它不是离线低功耗唤醒，也不是停止上传麦克风。未联网时不能用这两个自定义唤醒词。语音模块原有硬件唤醒事件也可开启会话。

| 语音 | 行为 |
| --- | --- |
| 开始追踪手 / 开始追踪脸 | 停止旧动作、更新模式，再由电脑检测相应目标 |
| 切换追踪模式 | 手/脸互换，清空旧目标和待发动作 |
| 停止追踪 | 两轴停转，拒绝旧版本的运动请求 |
| 调节亮度 | 询问需要多少亮度；60秒内回答“5”“五”或“亮度调整为5” |
| 亮度调整为0…10 | 直接设置；0关灯，其余开启白灯，换算为 round(级别×255/10)，5为128 |
| 开灯 / 关灯 | 保留所记亮度，切换灯开关 |
| 向左转 / 向右转 / 向上转 / 向下转 / 摇头 | 保留限时手动动作，单次20…500ms，不声称确认回位 |
| 查询某城市天气 | 云端墨迹天气插件 |
| 开始/停止/暂停/继续番茄时钟 | 云端插件下发 pomodoro start/stop/pause/resume |
| 停止聊天 | 仅关闭语音，继续接收／执行所有控制；再次唤醒恢复说话 |

新增完整坐姿语音指令：开启／关闭坐姿检测、校准坐姿、暂停／恢复坐姿追脸、查询坐姿状态、旋转画面、退出电脑程序。详见 `坐姿语音整合说明.md`。这些功能必须运行本版配套电脑程序；原版程序没有新增坐姿协议。

亮度越界、小数及非整数不会被截断成合法档位。中文“零…十”和“两”可用。手势的25/50/75/100%仍保留；手势关灯后调整档位只记住亮度，语音设置非零档位会直接亮灯。

## 电脑程序

运行本目录的电脑程序，旧目录程序没有新增的语音模式同步。安装与启动应针对同一份目录；可双击 setup_pc.cmd 安装。deliverables 解压副本也能复用上层同项目的已安装环境。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_pc.ps1
powershell -ExecutionPolicy Bypass -File .\run_pc.ps1 -DeviceHost 172.20.10.2 -Rotate 90
```

默认追踪关闭，语音、网页按钮或 F 开启。1手、2脸、M切换，F追踪开关，空格停止，P坐姿开关，C坐姿校准，R旋转，Q退出。

保留最新版连续手部检测、漏检全图/局部恢复、目标确认、骨架平滑、手/脸互斥、双轴跟随及坐姿检测。握拳仍需8帧窗口中6个真实画面且至少0.6秒，只点头及切灯一次；张手后才重新准备。点头前停200ms，低头300ms、停200ms、抬头300ms，速度0.025。

点动沿用1500μs中位、±75μs、100ms转动、200ms冷却，中位保持150ms后停PWM。检测丢失即停，画面超过900ms不接受新动作；电脑心跳超过3秒关闭追踪。图像走80端口，控制走81端口，网页旧80端口接口也可用。

## 验证和边界

验证状态以 `validation/STATUS.json` 为准。离线测试使用真实C/C++状态机、模拟时钟与PWM，不代表物理舵机角度、麦克风识别率、平台实时延迟或硬件稳定性已通过。需上板逐项验收：相机连续取图、手/脸切换、握拳点头/灯、两种叫法唤醒、连续两轮聊天、亮度追问、停止聊天后重新唤醒、天气以及番茄时钟四个操作。

番茄时钟本地默认专注25分钟、短休5分钟、长休15分钟、4轮；阶段结束由工作队列请求灵机播报，断网时无法云端播报。计时本身仍在设备继续运行。未增加断电续计时能力。

SDK的Agora传输不提供用户文本输入（send_text返回不支持），因此旧Arduino串口直接向DeepSeek输入自由文本、及其预留的外部视觉描述注入LLM接口，不属于本版已经完成的等价迁移；当前保留的是语音对话、网页相机和实际PC追踪/坐姿/灯控。若需要这两项开发接口，也需要平台提供相应正式协议，不能用“自定义播报”冒充文本推理。

语气摇头保留为灵机回复前缀的有限规则判断，仅在成功输出PCM时尝试一次，不再调用额外第三方模型；不是通用语义分类。

## 3.1.2 静音期间继续控制

说“停止聊天”后不再播放聊天、指令确认或坐姿／番茄时钟通知，已开启的追脸／追手保持原状态。直接说“开始坐姿检测”“校准坐姿”“开灯”等仍会执行，无需重新唤醒。说“你好小灵”或“你好小林”恢复说话。电脑端依旧需要运行才能执行电脑识别和校准；静音不会影响相应控制同步。在线初始待唤醒时也接受控制。语音输入依赖联网ASR，并未停止上传麦克风。
