# 坐姿语音整合版 3.1.2-silent-controls
以 Desktop/hack/final/FINAL 为最新基线，合入原 LJYD 可运行工程，保留 PID 11885 的本地有效产品配置。原 FINAL 目录未修改。当前构建、烧录及实机检查状态统一以 validation/STATUS.json 为准；不能把历史记录当成本版验收结果。

电脑程序运行且设备连云后，先说“你好小灵”或“你好小林”，随后说下列完整指令；也可连说“你好小灵，开启坐姿检测”。

| 指令 | 行为 |
|---|---|
| 开启坐姿检测 | 坐姿检测和自动追脸，暂停手势控制 |
| 校准坐姿 | 停稳镜头，鼻子、双眼、双肩可见后坐直采样；5秒内条件不满足会提示失败 |
| 暂停坐姿追脸 | 固定镜头，坐姿检测继续 |
| 恢复坐姿追脸 | 恢复自动追脸 |
| 查询坐姿状态 | 播报关闭、未校准、校准中或检测运行状态 |
| 关闭坐姿检测 | 关闭坐姿检测及自动追脸 |
| 旋转画面 | 顺时针90度并清除校准 |
| 退出电脑程序 | 停止追踪并关闭电脑检测窗口，重新使用需启动电脑程序 |
| 开始追踪手 / 开始追踪脸 | 退出坐姿模式并启用原有追踪 |
| 切换追踪模式 / 停止追踪 | 保留原语义；停止追踪不关闭坐姿检测 |
| 开灯 / 关灯 / 亮度调整为五 | 保留原灯控 |
| 调节亮度 | 原有亮度追问，回答零到十 |
| 停止聊天 | 只静音，保留已运行任务且继续接受坐姿／追踪／灯光控制；再次唤醒恢复语音 |

原有天气、番茄时钟、限时舵机动作和握拳灯控沿用原实现。坐姿异常使用灵机播报并闪三次琥珀灯，恢复最新灯状态。电脑端采用原有80图像/81控制双通道。

首次部署、配网、启动电脑服务、开发参数修改仍是安装配置步骤，不能声称断电或程序退出后还能靠该程序接收语音。运行期间原键盘操作仍保留。

启动：powershell -ExecutionPolicy Bypass -File .\run_pc.ps1 -DeviceHost 设备IP -Rotate 90
程序优先使用本目录 .venv；若从源码目录内的 deliverables 解压启动，会自动查找上层同项目已安装的 .venv。可用 -PythonPath 指定环境。双击 setup_pc.cmd 可安装当前这一份程序的环境。

验证：ESP-IDF 5.4.1 编译与分区大小检查通过；82项Python测试、47组真实C语音解析，以及原生C++控制器的坐姿开关／校准／暂停恢复／退出、心跳停转和最大计数1200字节JSON解析通过。真实C对话及灯控模拟测试通过。上述主机测试不代表麦克风、扬声器、物理舵机或真实坐姿已完成验收；烧录和启动结果另见 validation/STATUS.json。
